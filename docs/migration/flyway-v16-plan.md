## 2. V16__reports.sql Scope (Track A, ŞIMDI)

### Tablolar (4)

```sql
-- V16__reports.sql (platform-ssot/backend/report-service/src/main/resources/db/migration/)

-- ===== 1. reports — Authoritative (MSSQL REPORTS) =====
CREATE TABLE IF NOT EXISTS reports_db.reports (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    source_mssql_id BIGINT UNIQUE NOT NULL,      -- idempotency key
    key VARCHAR(128) UNIQUE NOT NULL,
    title VARCHAR(512) NOT NULL,
    category VARCHAR(128) NOT NULL DEFAULT 'Uncategorized',
    source_schema VARCHAR(128),                  -- '{schema}' parametric veya literal
    schema_mode VARCHAR(32) NOT NULL DEFAULT 'static',  -- yearly | static | standard
    year_column VARCHAR(64),                     -- yearly mode için
    source_table VARCHAR(128),                   -- direct source (23 rapor)
    source_query TEXT,                           -- sourceQuery (8 rapor — annex 2A manual validated)
    contains_nolock_hint BOOLEAN NOT NULL DEFAULT false,
    definition_jsonb JSONB,                      -- full JSON spec (columns, parameters, filters)
    content_hash CHAR(32),                       -- md5 idempotent re-run marker
    deleted_flag BOOLEAN NOT NULL DEFAULT false, -- soft-delete (pg partial index)
    deleted_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_reports_key ON reports_db.reports (key) WHERE deleted_flag = false;
CREATE INDEX idx_reports_category ON reports_db.reports (category) WHERE deleted_flag = false;
CREATE INDEX idx_reports_content_hash ON reports_db.reports (content_hash);

-- View pattern (Codex iter-4 AGREE; @Where repo pattern değil)
CREATE OR REPLACE VIEW reports_db.v_reports_active AS
SELECT * FROM reports_db.reports WHERE deleted_flag = false;


-- ===== 2. saved_reports — Authoritative (MSSQL SAVED_REPORTS) =====
CREATE TABLE IF NOT EXISTS reports_db.saved_reports (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),    -- hybrid: multi-source merge riski
    source_mssql_id BIGINT UNIQUE NOT NULL,
    user_id VARCHAR(128) NOT NULL,                    -- KC sub veya user_service UUID
    report_key VARCHAR(128) NOT NULL,                 -- FK → reports.key (soft, view filter)
    parameters JSONB NOT NULL DEFAULT '{}'::jsonb,
    custom_title VARCHAR(512),
    shared_with_org BOOLEAN NOT NULL DEFAULT false,
    deleted_flag BOOLEAN NOT NULL DEFAULT false,
    revoked_at TIMESTAMPTZ,                            -- soft-delete alternative
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    UNIQUE (user_id, report_key)
);

CREATE INDEX idx_saved_reports_user ON reports_db.saved_reports (user_id) WHERE deleted_flag = false;
CREATE INDEX idx_saved_reports_report_key ON reports_db.saved_reports (report_key);

CREATE OR REPLACE VIEW reports_db.v_saved_reports_active AS
SELECT * FROM reports_db.saved_reports
WHERE deleted_flag = false AND (revoked_at IS NULL OR revoked_at > now());


-- ===== 3. wc_permissions_snapshot — Cache-reference (MSSQL PERMISSIONS) =====
-- Tentative cache-ref; actual migration_action Faz 16.1 annex SEAL sonrası netleşir
CREATE TABLE IF NOT EXISTS reports_db.wc_permissions_snapshot (
    source_mssql_id BIGINT PRIMARY KEY,
    permission_code VARCHAR(128) NOT NULL,
    module_code VARCHAR(128),
    description TEXT,
    is_active BOOLEAN NOT NULL DEFAULT true,
    snapshot_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    UNIQUE (permission_code, module_code)
);

CREATE INDEX idx_wc_permissions_module ON reports_db.wc_permissions_snapshot (module_code) WHERE is_active = true;


-- ===== 4. wc_modules_snapshot — Cache-reference (MSSQL MODULES) =====
CREATE TABLE IF NOT EXISTS reports_db.wc_modules_snapshot (
    source_mssql_id BIGINT PRIMARY KEY,
    module_code VARCHAR(128) UNIQUE NOT NULL,
    module_name VARCHAR(256) NOT NULL,
    parent_module_id BIGINT,
    display_order INT,
    is_active BOOLEAN NOT NULL DEFAULT true,
    snapshot_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_wc_modules_parent ON reports_db.wc_modules_snapshot (parent_module_id) WHERE is_active = true;


-- ===== FK constraints NOT VALID (16.3 ETL sonunda VALIDATE) =====
ALTER TABLE reports_db.wc_permissions_snapshot
    ADD CONSTRAINT fk_wc_permissions_module
    FOREIGN KEY (module_code)
    REFERENCES reports_db.wc_modules_snapshot (module_code)
    NOT VALID;
-- 16.3 ETL post-load: ALTER TABLE ... VALIDATE CONSTRAINT fk_wc_permissions_module;

-- saved_reports → reports FK: soft FK (view filter ile enforce, hard constraint yok)
-- Çünkü reports soft-delete ile child orphan olur; view pattern (Codex §8.3).

-- ===== Sequence setval YOK =====
-- Codex AGREE: 16.3 ETL post-load sırasında `setval(pg_get_serial_sequence(...))`
-- V16 sadece DDL; setval IDENTITY table için ETL bitince.
```

### Index Stratejisi

- **Partial index** soft-delete için (`WHERE deleted_flag = false`) — reconciliation 16.3.5 aktif+soft-deleted toplam sayım yapar ama yaygın query active'a bakar
- **Unique**: `source_mssql_id` (idempotent UPSERT key), `key` (natural), composite `(user_id, report_key)`
- **View**: `v_reports_active`, `v_saved_reports_active` — ORM entity `@Table(name="v_..._active")` veya native query

## 3. V16__schemas.sql (Track B, BEKLET)

**Önce**: `docs/migration/schema-service-parity-adr.md` mühürlenmeli.

### Option A — Live PG catalog (code rewrite)

V16 SQL **anlamsız/no-op** — schema-service runtime'da `pg_tables`/`pg_views`'e direkt sorgu yapar. Migration yok.

Değişikliklerin tümü platform-ssot schema-service:
- `SchemaExtractService.java` MSSQL `sys.*` → PG `pg_catalog.*` query rewrite
- `application-k8s.yml` datasource: mssql → postgres (primary)
- `MssqlConfig.java` kaldırıldı veya secondary
- Integration test: PG meta-catalog'dan beklenen schema enumeration

### Option B — ETL-ed metadata snapshot

`V16__schemas.sql` (platform-ssot/backend/schema-service/src/main/resources/db/migration/):

```sql
-- V16__schemas.sql (schema-service PG Flyway datasource yeni wire'lanır)

CREATE SCHEMA IF NOT EXISTS schemas_db;

CREATE TABLE IF NOT EXISTS schemas_db.metadata_snapshot (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    source_type VARCHAR(32) NOT NULL,        -- table | view | procedure | function
    schema_name VARCHAR(128) NOT NULL,
    object_name VARCHAR(256) NOT NULL,
    object_definition TEXT,                   -- view/procedure definition
    column_count INT,
    row_count_approx BIGINT,
    snapshot_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    UNIQUE (schema_name, object_name, source_type)
);

CREATE INDEX idx_metadata_schema ON schemas_db.metadata_snapshot (schema_name);
CREATE INDEX idx_metadata_object ON schemas_db.metadata_snapshot (object_name);

CREATE TABLE IF NOT EXISTS schemas_db.column_snapshot (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    metadata_id BIGINT NOT NULL REFERENCES schemas_db.metadata_snapshot (id) ON DELETE CASCADE,
    column_name VARCHAR(256) NOT NULL,
    data_type VARCHAR(64) NOT NULL,           -- observed MSSQL type
    max_length INT,
    is_nullable BOOLEAN NOT NULL DEFAULT true,
    is_primary_key BOOLEAN NOT NULL DEFAULT false,
    ordinal_position INT,
    snapshot_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_column_metadata ON schemas_db.column_snapshot (metadata_id);

-- Refresh job (16.3 ETL worker periyodik refresh mode)
```

**Refresh job**: K8s CronJob veya ETL worker `--mode=metadata-refresh` (her N saat).
