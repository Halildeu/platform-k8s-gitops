## 2. git filter-repo path strategy

### Backend filter

```bash
cd /tmp/faz-19-migration/backend-filter-dryrun.git  # mirror clone
git filter-repo --path backend/ --path-rename backend/:
```

**Result:**
- Original ssot: 2,696 commits + 275M packed
- After filter: **338 commits + 3.7M packed** (backend/-touching commits only)
- Top-level files after rename: `.env.example`, `.env.prod.example`, `.github/`, `.gitignore`, `.mvn/`, `.vscode/`, `README.md`, `api-gateway/`, `auth-service/`, `backend/` (nested), `common-auth/`, `core-data-service/`, `discovery-server/`, `openfga/`, `permission-service/`, `pom.xml`, `report-service/`, `schema-service/`, `user-service/`, `variant-service/` + more

### Web filter

```bash
cd /tmp/faz-19-migration/web-filter-dryrun.git
git filter-repo --path web/ --path-rename web/:
```

**Result:**
- After filter: **739 commits + 106M packed** (web/-touching commits only)
- Top-level files: `.claude/`, `.codecov.yml`, `.commitlintrc.cjs`, `.dockerignore`, `.env.i18n.example`, `.env.local.example`, `.figma-sync-state.json`, `.github/`, `.gitignore`, `.husky/`, `apps/`, `packages/`, `design-tokens/`, ...

### Neden sadece tek `--path` (Codex multi-path'ten sapma)

Codex önerisi: `--path backend/ --path .github/workflows/ --path-rename backend/:`. Ama yapıldığında `backend/.github/workflows/release-canary.yml` ↔ `/.github/workflows/release-canary.yml` collision:

```
File renaming caused colliding pathnames!
  Filename: b'.github/workflows/release-canary.yml'
```

Çünkü hem root `.github/workflows/` hem de `backend/.github/workflows/` mevcut. Collision fix: sadece `backend/` path. Root `.github/workflows/` yeni repo'da sağdan kurulacak (dual-build transition dönemi 19.8'de).
