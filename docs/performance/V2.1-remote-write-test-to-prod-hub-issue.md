### 3.2 Kısa-vadeli mitigation (V2.1 follow-up, opsiyonel)

**Pattern A: Prod-hub Prom remote_write_receiver enable**

```yaml
# helm-values/kube-prometheus-stack/values-prod.yaml
prometheus:
  prometheusSpec:
    enableRemoteWriteReceiver: true   # YENİ
```

Sonra service `kube-prometheus-stack-prometheus.monitoring.svc.cluster.local:9090` endpoint açar.

**Pattern B: Test Prom remote_write URL düzelt**

`helm-values/kube-prometheus-stack/values-test.yaml` satır 41:
```yaml
remoteWrite:
  - url: "http://kube-prometheus-stack-prometheus.monitoring.svc.cluster.local:9090/api/v1/write"
```

**ANCAK**: Test cluster (k3d-test) ile prod cluster (k3d-prod) **ayrı K8s network namespace**'leri. Aynı staging-sw host'unda ama cluster network izole. K3d cluster'lar arası direct service erişim YOK; routing katmanı gerek:
- (a) Host-level proxy/ingress (staging-sw nginx)
- (b) Cross-cluster mesh (Cilium ClusterMesh, Istio multi-cluster)
- (c) Prod cluster Prometheus host port expose + test cluster DNS override

Bu non-trivial — V2.1 scope dışı.
