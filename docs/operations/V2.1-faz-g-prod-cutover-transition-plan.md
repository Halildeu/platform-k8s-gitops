## 4. Rollback Trigger Criteria (Explicit)

Aşağıdaki **HERHANGI BIR** koşul karşılanırsa **otomatik rollback** (T+5min → T+72h window):

### 4.1 Latency / Error Rate Triggers

- API gateway p95 latency **>+50%** baseline (5min rolling window)
- HTTP 5xx rate **>+2%** baseline (5min rolling)
- Synthetic alert PerfFederationSmokeFailing firing (federation chain break)

### 4.2 Operational Triggers

- Pod CrashLoopBackOff > 1 instance / kritik servis (api-gateway, auth-service, user-service)
- ESO `SecretSynced=False` > 3 ExternalSecret simultaneously (Vault chain broken)
- Edge nginx 502/503 spike (k8s upstream unreachable)

### 4.3 Sustained Triggers

- ABM-1 smoke `result=FAIL` (federation/cache invariant violation)
- 3+ different alerts firing within 5min (alert storm)

### 4.4 Manual Trigger

- Owner explicit "rollback" sign-off (named decision, audit-logged)
