## Bilinen governance debt (follow-up)

1. **AuthGate `prompt: login` PR (platform-web)** — SSO-cookie'li canonical suite session'ı `ethics:case:manage` scope taşımıyorsa `denied` cycle'a takılıyor. Fix: `keycloak.login({..., prompt: 'login'})` — pnpm dep engelinden bu turda bekletildi.

2. **X-Etik-Speak-Transport ingress render** — cluster ingress-nginx `proxy-set-headers` ConfigMap'ten sadece `Authorization: ""` render ediyor, `X-Etik-Speak-Transport: https` atlıyor (v1.9+ quirk). `configuration-snippet` bypass modern security tarafından "risky" reject. **Live workaround**: `ETHICS_SECURE_TRANSPORT_REQUIRED=false` env var (backend'in built-in toggle'ı) — bu evidence'e yol açtı. **Kalıcı canonical fix**: (a) ingress-nginx-controller ConfigMap `allow-snippet-annotations: true` + `annotations-risk-level: Critical` + activation ingress'lerde `configuration-snippet` annotation; (b) backend `PublicCredentialBoundaryFilter.hasAuthorization` check empty-string bypass + `X-Forwarded-Proto: https` fallback kabul.

3. **Edge nginx canonical drift** — aktif `platform-web-nginx` container `/home/halil/platform/web/nginx/default.conf` (out-of-git manual-managed) kullanıyor; repo `host-compose/web-nginx/default.conf` PR #2718 merged ancak henüz canonical deployment değil. Follow-up: compose-based canonical deployment.
