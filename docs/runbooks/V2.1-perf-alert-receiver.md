## 1. Bağlam

Performance regression detect (PerfFederationSmokeFailing, PerfFederationSmokeResultFail, PerfFederationSmokeStale, vb.) → Alertmanager → Slack `#perf-alerts` kanalı delivery. Single-team focus; D43 drift `alarm-receiver-bridge` pipeline'ından AYRI Slack kanalı (A2 isolation).

Chain:
```
PrometheusRule (frontend-federation-smoke-alerts, 5 alert)
  → Prometheus operator pick-up
  → Alert evaluator state (inactive/pending/firing)
  → Alertmanager (team=perf matcher route)
  → perf-alerts-slack receiver
  → Slack workspace #perf-alerts
```

## 4. Throttle + dedupe policy

| Parameter | Değer | Rationale |
|---|---|---|
| `group_wait` | 30s | İlk alert için kısa wait — perf reg quick visibility |
| `group_interval` | 5m | Aynı grup için tekrar interval — alarm storm prevent |
| `repeat_interval` | 6h | Sustained firing için günde max 4 hatırlatma — fatigue control |
| `group_by` | [alertname, namespace] | Test/prod ayrımı net + her alert ayrı grouping |

**Dedupe key**: `alertname` + `namespace`. Aynı alert aynı namespace'te tek mesaj, severity transition log'lanır.

**Resolved lifecycle**: `send_resolved: true` — firing → resolved transition'da `[RESOLVED]` prefix ile mesaj döner; manuel close gerek değil.

## 5. Fail mod handling

### 5.1 Vault path yok / yazılmadı

- ESO: `SecretSynced=False`, condition message: `key kv/platform/perf-alertmanager not found`
- K8s Secret: oluşmaz
- Alertmanager pod start: secret mount fail → pod CrashLoopBackOff
- **Fix**: Owner Vault write tamamlanana kadar perf-alertmanager-secrets ESO comment-out veya placeholder dummy webhook URL yazılır

### 5.2 Slack webhook geçersiz / expired

- Alertmanager log: `level=warn msg="Notify attempt failed" receiver=perf-alerts-slack err="server returned HTTP status 404 Not Found"`
- **Fix**: Yeni webhook URL Slack workspace → Vault write → ESO refresh (max 1h)

### 5.3 Drill window aktif (D43)

- D43 drill aktif iken Alertmanager config drill override yüklü (`helm-values-test-d43-drill.yaml`)
- Drill override `receivers`/`routes` array'leri baseline'daki perf receiver'ı **shadow edebilir**
- **Fix**: Drill window kapanışı bekle veya drill values'a `perf-alerts-slack` receiver + route patch ekle (impl PR gerekirse Ops-A follow-up)

### 5.4 Alertmanager pod restart sırasında alert kayıp

- Alertmanager replica=1 (D21 single replica); pod restart sırasında ~30s downtime
- Sustained alert'ler (`for: 5m`) restart sonrası tekrar pick-up edilir (Prom side eval state tutar)
- **Mitigation**: Critical alarmlar için replica=2 V3 backlog'a
