## 1. Bağlam

Performance regression detect (PerfFederationSmokeFailing, PerfFederationSmokeResultFail, PerfFederationSmokeStale, vb.) → Alertmanager → Microsoft Teams `#perf-alerts` channel delivery (Power Automate workflow → Adaptive Card). Single-team focus; D43 drift `alarm-receiver-bridge` pipeline'ından AYRI Teams channel (A2 isolation).

Chain:
```
PrometheusRule (frontend-federation-smoke-alerts, 5 alert)
  → Prometheus operator pick-up
  → Alert evaluator state (inactive/pending/firing)
  → Alertmanager (team=perf matcher route)
  → perf-alerts-teams receiver (webhook_configs.url_file)

```

```

            "namespace": "platform-prod",
            "alert_class": "synthetic-smoke"
          },
          "annotations": {
            "description": "Perf smoke failing for 5m",
            "summary": "Perf regression detected",
            "runbook_url": "https://github.com/Halildeu/platform-k8s-gitops/blob/main/docs/runbooks/V2.1-perf-alert-receiver.md"
          },
          "status": "firing",
          "startsAt": "2026-05-28T10:00:00Z"
        }],
        "status": "firing",
        "groupLabels": {"alertname": "PerfFederationSmokeFailing"},
        "commonLabels": {"team": "perf", "severity": "warning"}

3. Action: "Post adaptive card in a chat or channel"
```

### 2.2 Adaptive Card body template (perf-specific)

Power Automate flow "Post adaptive card" action body alanına yapıştır (Codex `019e6b24` iter-2 perf-specific schema önerisi):

```json
{
  "$schema": "http://adaptivecards.io/schemas/adaptive-card.json",
  "type": "AdaptiveCard",
  "version": "1.4",
  "body": [
    {
      "type": "TextBlock",
      "size": "Large",
      "weight": "Bolder",
      "text": "🚨 V2.1 Perf Alert | @{first(triggerBody()?['alerts'])?['labels']?['alertname']}",
      "color": "@{if(equals(first(triggerBody()?['alerts'])?['labels']?['severity'], 'critical'), 'Attention', 'Warning')}"
    },
    {
      "type": "FactSet",
      "facts": [
        {"title": "Status:", "value": "@{toUpper(triggerBody()?['status'])}"},
        {"title": "Severity:", "value": "@{first(triggerBody()?['alerts'])?['labels']?['severity']}"},
        {"title": "Namespace:", "value": "@{first(triggerBody()?['alerts'])?['labels']?['namespace']}"},
        {"title": "Alert class:", "value": "@{first(triggerBody()?['alerts'])?['labels']?['alert_class']}"},
        {"title": "Started:", "value": "@{first(triggerBody()?['alerts'])?['startsAt']}"}
      ]
    },
    {
      "type": "TextBlock",
      "text": "@{first(triggerBody()?['alerts'])?['annotations']?['description']}",
      "wrap": true
    }
  ],
  "actions": [
    {
      "type": "Action.OpenUrl",
      "title": "📖 Runbook",
      "url": "@{coalesce(first(triggerBody()?['alerts'])?['annotations']?['runbook_url'], 'https://github.com/Halildeu/platform-k8s-gitops/blob/main/docs/runbooks/V2.1-perf-alert-receiver.md')}"
    }
  ]
}
```

**Resolved transition**: send_resolved=true (helm-values), Alertmanager `status=resolved` ile aynı flow'u POST eder → Adaptive Card title prefix `[RESOLVED]` veya color farklılaştırma flow conditional ile.

## 4. Throttle + dedupe policy

| Parameter | Değer | Rationale |
|---|---|---|
| `group_wait` | 30s | İlk alert için kısa wait — perf reg quick visibility |
| `group_interval` | 5m | Aynı grup için tekrar interval — alarm storm prevent |
| `repeat_interval` | 6h | Sustained firing için günde max 4 hatırlatma — fatigue control |
| `group_by` | `[alertname, namespace]` | Test/prod ayrımı net + her alert ayrı grouping |

**Dedupe key**: `alertname` + `namespace`. Aynı alert aynı namespace'te tek mesaj, severity transition log'lanır.

**Resolved lifecycle**: `send_resolved: true` — firing → resolved transition'da Adaptive Card resolved-state ile gelir (Power Automate flow conditional title prefix `[RESOLVED]` veya color farklılaştırma); manuel close gerek değil.

## 5. Fail mod handling

### 5.1 Vault path yok / TEAMS_WEBHOOK_URL yazılmadı

- ESO: `Ready=False (reason=SecretSyncedError)`, condition message: `property TEAMS_WEBHOOK_URL not found in kv/platform/perf-alertmanager`
- K8s Secret: oluşmaz (Codex `019e6b24` iter-2 catch: pod davranışı senaryoya bağlı)
  - **Senaryo A** — Secret hiç yok (ESO sync hiç çalışmamış): pod start sırasında `MountVolume.SetUp failed: secret "perf-alertmanager-teams-secrets" not found` → pod state `ContainerCreating` veya `Pending` (CrashLoop değil)
  - **Senaryo B** — Secret var ama `TEAMS_WEBHOOK_URL` key empty/missing (ESO partial sync): pod start success ama Alertmanager notify path file-not-found → `level=warn msg="Notify attempt failed" err="open ...TEAMS_WEBHOOK_URL: no such file or directory"`; CrashLoop nadiren
- **Fix**: Owner Vault write tamamlanana kadar §2.3 yürütülmeli; veya `kustomization.yaml` `externalsecret-perf-alertmanager-teams.yaml` geçici comment-out

### 5.2 Power Automate workflow geçersiz / expired

- Alertmanager log: `level=warn msg="Notify attempt failed" receiver=perf-alerts-teams err="server returned HTTP status 404 Not Found"` veya `401 Unauthorized` veya `429 Too Many Requests` (quota)
- **Fix**: Power Automate workspace'te flow status check; pasif (disabled) ise activate; quota exhausted ise license review; yeni workflow URL üret → Vault overwrite (`vault kv patch` aynı path) → ESO refresh (max 1h veya force-sync annotate)
- **R29 active drift mitigation chain**: monthly synthetic Teams smoke + flow run-history failed-run monitoring

### 5.3 Drill window aktif (D43)

- D43 drill aktif iken Alertmanager config drill override yüklü (`helm-values-test-d43-drill.yaml`)
- Drill override `receivers`/`routes` array'leri baseline'daki perf receiver'ı **shadow edebilir**
- **Fix**: Drill window kapanışı bekle veya drill values'a `perf-alerts-teams` receiver + route patch ekle (impl PR gerekirse Ops-A follow-up)

### 5.4 Alertmanager pod restart sırasında alert kayıp

- Alertmanager replica=1 (D21 single replica); pod restart sırasında ~30s downtime
- Sustained alert'ler (`for: 5m`) restart sonrası tekrar pick-up edilir (Prom side eval state tutar)

### 5.5 Power Automate run-history fail (Adaptive Card transform)

- Flow run-history'de `Failed` status + Adaptive Card body parse hatası
- **Fix**: Adaptive Card JSON template `triggerBody()` dynamic content expression syntax check; `first()` + `?` null-safe operator pattern; Alertmanager v4 payload schema doğru parse ediliyor mu Flow test trigger ile verify
