### §3.2 Fire-by-fire observation (Codex `019e269e` blocking-1 absorb)

Her fire sonrası (status CM güncellenirse). **Pattern**: `-o json | jq -c` (compact, one-line JSONL contract):

```bash
# Snapshot — enriched JSONL line (PMD partial metadata + observer-lag jq computed)
# Codex `019e269e` tur-2 must-fix-1: test ve prod için ayrı okuma (cross-cluster kirletme önle)

snapshot_fire() {
  local cluster="$1"
  local ns="platform-${cluster}"
  local out="/tmp/abm-1-${cluster}-soak.jsonl"
  local t=$(date -u +%Y-%m-%dT%H:%M:%SZ)

  # Cluster-specific image digest + image ref (build_sha annotation yoksa fallback)
  local img_ref=$(ssh halil@staging-sw "kubectl --context k3d-${cluster} -n ${ns} get pod -l app.kubernetes.io/name=frontend -o jsonpath='{.items[0].spec.containers[0].image}'" 2>/dev/null || echo "unknown")
  local img_digest=$(ssh halil@staging-sw "kubectl --context k3d-${cluster} -n ${ns} get pod -l app.kubernetes.io/name=frontend -o jsonpath='{.items[0].status.containerStatuses[0].imageID}'" 2>/dev/null | awk -F'@' '{print $NF}' || echo "unknown")
  local build_sha=$(ssh halil@staging-sw "kubectl --context k3d-${cluster} -n ${ns} get deploy frontend -o jsonpath='{.spec.template.metadata.annotations.build-sha}'" 2>/dev/null || echo "unknown")

  ssh halil@staging-sw "kubectl --context k3d-${cluster} -n ${ns} get cm frontend-federation-smoke-status -o json" 2>/dev/null \
    | jq -c --arg t "$t" --arg cluster "$cluster" --arg bs "$build_sha" --arg id "$img_digest" --arg ref "$img_ref" \
        '.data as $d | $d + {
          observed_at: $t,
          cluster: $cluster,
          build_sha: $bs,
          frontend_image_ref: $ref,
          frontend_image_digest: $id,
          observed_lag_seconds: (try (($t | fromdateiso8601) - ($d.lastFire | fromdateiso8601)) catch null)
        }' \
    >> "$out"
}

# Her cluster için bağımsız snapshot
snapshot_fire test
snapshot_fire prod
```

**Codex tur-2 must-fix absorb**:
- (1) Test ve prod için ayrı `kubectl ... -n platform-${cluster}` (cross-cluster metadata kirletme önle)
- (2) `frontend_image_ref` eklendi (`build_sha` unknown durumunda traceability)
- (3) `observed_lag_seconds` jq computed (`observed_at - lastFire`; semantik: observer'ın fire'ı ne kadar geç gördüğü — scheduler lag DEĞİL)

**Codex blocking-1 fix**: `-o jsonpath='{.data}'` yerine `-o json | jq -c '.data + {...}'` → pretty-print yok, **one fire = one line** JSONL contract garantili.

**Codex blocking-3 + tur-2 + tur-3 absorb**: ABM-1 artifact metadata = `cluster + build_sha + frontend_image_ref + frontend_image_digest + observed_lag_seconds`. ABM-1 **cluster-internal curl-only detector** (CronJob script bash + curl + jq; Playwright/browser profile DEĞİL). Full PMD #8 `route_scope/auth_persona/browser_version/cache_mode` metadata **M2a1 + route-budget gate kapsamı** — §8 detay.

## §9. Code Snippet Library

### §9.1 Soak observer one-shot

```bash
#!/usr/bin/env bash
# scripts/perf/abm-1-soak-observer.sh
# Continuous fire observer (run on staging-sw or local with SSH)
# Codex `019e269e` tur-1+tur-2 absorb: one-line JSONL + DOC reset + full schema
set -euo pipefail

CLUSTER="${1:-test}"  # test or prod
NS="platform-${CLUSTER}"
OUT="/tmp/abm-1-${CLUSTER}-soak.jsonl"
LAST_FIRE=""

# Signal handler — graceful exit + final state echo
trap 'echo "[ABM-1 $CLUSTER] terminated — soak output: $OUT (lines: $(wc -l < "$OUT" 2>/dev/null || echo 0))"; exit 0' INT TERM

while true; do
  T=$(date -u +%Y-%m-%dT%H:%M:%SZ)
  DOC=""  # Codex tur-2: reset her loop başında (stale data masking önle)

  # SSH retry: 3 attempts with exponential backoff
  for attempt in 1 2 3; do
    DOC=$(ssh halil@staging-sw "kubectl --context k3d-${CLUSTER} -n ${NS} get cm frontend-federation-smoke-status -o json" 2>/dev/null) && break
    DOC=""
    sleep $((attempt * 5))   # 5/10/15s
  done

  if [ -z "$DOC" ]; then
    echo "[ABM-1 $CLUSTER] SSH/kubectl failed after 3 retries; skip cycle"
    sleep 300; continue
  fi

  # Full schema metadata
  IMG_REF=$(ssh halil@staging-sw "kubectl --context k3d-${CLUSTER} -n ${NS} get pod -l app.kubernetes.io/name=frontend -o jsonpath='{.items[0].spec.containers[0].image}'" 2>/dev/null || echo "unknown")
  IMG_DIGEST=$(ssh halil@staging-sw "kubectl --context k3d-${CLUSTER} -n ${NS} get pod -l app.kubernetes.io/name=frontend -o jsonpath='{.items[0].status.containerStatuses[0].imageID}'" 2>/dev/null | awk -F'@' '{print $NF}' || echo "unknown")
  BUILD_SHA=$(ssh halil@staging-sw "kubectl --context k3d-${CLUSTER} -n ${NS} get deploy frontend -o jsonpath='{.spec.template.metadata.annotations.build-sha}'" 2>/dev/null || echo "unknown")

  CURRENT_FIRE=$(echo "$DOC" | jq -r '.data.lastFire // ""')
  if [ "$CURRENT_FIRE" != "$LAST_FIRE" ] && [ -n "$CURRENT_FIRE" ]; then
    # JSONL contract: ONE LINE per fire, full enriched schema (Codex tur-2 must-fix-3)
    echo "$DOC" | jq -c --arg t "$T" --arg cluster "$CLUSTER" --arg bs "$BUILD_SHA" --arg id "$IMG_DIGEST" --arg ref "$IMG_REF" \
      '.data as $d | $d + {
        observed_at: $t,
        cluster: $cluster,
        build_sha: $bs,
        frontend_image_ref: $ref,
        frontend_image_digest: $id,
        observed_lag_seconds: (try (($t | fromdateiso8601) - ($d.lastFire | fromdateiso8601)) catch null)
      }' \
      >> "$OUT"
    echo "[ABM-1 $CLUSTER] new fire $CURRENT_FIRE — result=$(echo "$DOC" | jq -r .data.result)"
    LAST_FIRE="$CURRENT_FIRE"
  fi
  sleep 300  # 5 minute poll interval
done
```

### §9.2 Soak summary report

```bash
#!/usr/bin/env bash
# scripts/perf/abm-1-soak-report.sh
set -euo pipefail

CLUSTER="${1:-test}"
JSONL="/tmp/abm-1-${CLUSTER}-soak.jsonl"

if [ ! -f "$JSONL" ]; then
  echo "ABM-1 $CLUSTER: no soak data ($JSONL)"
  exit 2
fi

TOTAL=$(wc -l < "$JSONL")
PASS=$(jq -s 'map(select(.result == "PASS")) | length' "$JSONL")
FAIL=$((TOTAL - PASS))

echo "ABM-1 $CLUSTER soak summary"
echo "  Total fires:    $TOTAL"
echo "  PASS:           $PASS"
echo "  FAIL:           $FAIL"
echo "  Clean ratio:    $(echo "scale=2; $PASS * 100 / $TOTAL" | bc)%"

if [ "$FAIL" -gt 0 ]; then
  echo ""
  echo "  FAIL detail:"
  jq -s 'map(select(.result != "PASS"))' "$JSONL"
fi
```
