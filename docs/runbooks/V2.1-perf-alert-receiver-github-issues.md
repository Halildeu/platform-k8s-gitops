## 4. Failure Mode Handling

### 4.1 PAT Expired / Revoked

- Alertmanager log: `level=warn msg="Notify attempt failed" receiver=perf-alerts-github-issues err="server returned HTTP status 401"`
- Fix: Step 2.1 retry + Step 2.2 secret update + pod restart

### 4.2 GHA Workflow Permission Error

- Workflow run log: `gh: HTTP 403`
- Fix: `permissions:` block kontrol (`issues: write` mandatory)
- Repo settings: Actions → General → Workflow permissions → "Read and write"

### 4.3 Dedupe Race (concurrent firing)

- Aynı alert paralel webhook → 2 issue create riski
- Mitigation: workflow `timeout-minutes: 5` + GitHub Issues API atomic; race window small
- Owner manuel: 2 issue açılırsa eski olanı close + comment "duplicate of #<new>"

### 4.4 Alertmanager Webhook Rate Limit

- GitHub API 5000 req/h auth'd
- Mitigation: throttle config (`group_interval: 5m`, `repeat_interval: 6h`); 4x/gün/alert max
- Rate limit yaklaşırsa: webhook proxy (n8n, GHA workflow buffer)
