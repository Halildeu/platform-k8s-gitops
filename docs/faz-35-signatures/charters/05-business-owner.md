# Business Owner — Charter (Faz 35 ES-311)

**Rol**: Ürünün ticari + operasyonel + finansal sorumluluğu.

## Neyi taahhüt ediyorum

### Ticari sürdürülebilirlik

- [ ] Etik Speak kanalının sürekliliği için yıllık bütçe garanti edilir:
  - Cloud infrastructure (k3d cluster + backup storage + observability)
  - Personnel (Reveal Officer + On-call rotasyon compensation)
  - Legal advisor retainer (Legal Owner + Compliance + DPO danışmanlık)
  - Compliance audit (yıllık iç + 2 yılda bir üçüncü taraf)
  - Insurance (cyber liability + professional indemnity)
- [ ] Ürünün stratejik değeri leadership'e yıllık raporlanır
- [ ] Muhbir kanalı ticari değil hukuki taahhüt — kâr merkezi olarak yönetilmez

### Süreç sahipliği

- [ ] Rol atamaları (bu paketteki 7 rol) + devir süreçleri sahibiyim
- [ ] Rol boş kalırsa **24 saat içinde** vekil ataması yaparım
- [ ] Yıllık charter yenileme koordinasyonu
- [ ] Rol conflict of interest denetimi (ör. Reveal Officer'in kendi yönettiği departmanla ilgili bildiriyi görmemesi)

### Stakeholder iletişim

- [ ] Yönetim kurulu + üst yönetim düzenli briefleme (çeyrek yıllık)
- [ ] Şirket-içi duyurular (kanal açık, kullanım politikası, anti-misilleme)
- [ ] Regulatuar/hukuki değişiklikleri leadership'e ilet
- [ ] Bildirim istatistikleri (yıllık — anonimize) kamu raporlarına dahil edilebilir (opsiyonel)

### Kriz yönetimi

- [ ] Kanuni ihlal, denetim başarısızlığı, veri sızıntısı, medya yansıması durumlarında:
  1. Kriz komitesi kurar (Legal + DPO + Compliance + PR)
  2. Kamu iletişimi koordine eder
  3. Restore + iyileştirme adımlarının bütçesini onaylar
  4. Rol değişikliği gerekirse hızlı karar verir
- [ ] Kriz sonrası post-mortem + iyileştirme owner

### Ürün pivot / kapatma kararı

- [ ] Kanal kapatma kararı **owner + Legal + DPO ortak** — tek başına alınamaz
- [ ] Kapatma öncesi çalışanlara + muhbirlere 90 gün önceden bildirim (ISO 37002 uygulanabilir)
- [ ] Kapatma sonrası veri saklama + audit trail koruma (retention policy hâlâ geçerli)

## Süre + yenileme

- 1 yıl geçerli
- Şirket yönetim değişikliği durumunda 30 gün içinde yeni Business Owner ataması
